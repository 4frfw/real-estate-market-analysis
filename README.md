# Исследование рынка недвижимости
Чичилов Кирилл · ЧЛБ25-ИУП-БИ01 · тема №9. Россия, 2019–2024.

Источники: data/sources.md. Исходные CSV: data/raw. Расчёт: scripts/analyze.py. Проверки: tests.
Запуск: pip install -r requirements.txt; python -m unittest discover -s tests -v; python scripts/analyze.py.
Результаты: reports/market.xlsx, data/processed, site/index.html. Средняя цена не равна индексу; корреляция по 6 годам не доказывает причинность. S1 исключает Крым и Севастополь.
Word, PDF и презентация переданы в итоговом ZIP. Они не обновляются автоматически по CSV. Actions пересчитывает и фиксирует результаты, сохраняет артефакты и пытается включить Pages. Если прав недостаточно: Settings → Pages → GitHub Actions. Успех подтверждается фактическим run.
Еженедельный backup создаёт проверенный архивный релиз. Wiki, Discussions, Projects, реальная история burndown и независимая копия требуют отдельной фактической приёмки; их выполнение не заявляется по наличию шаблонов.
