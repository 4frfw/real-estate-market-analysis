# Исследование рынка недвижимости

Динамика цен и влияние макрофакторов на первичный и вторичный рынки жилья России за 2019–2024 годы.

Автор: Чичилов Кирилл.
Группа: ЧЛБ25-ИУП-БИ01.
Дисциплина: «Технологии хранения данных». Тема №9.

## Цель

Сопоставить динамику двух сегментов рынка, отделить номинальный рост от инфляции и исследовать связи ценовых индексов с макроэкономическими показателями. Организовать воспроизводимое хранение, обработку и визуализацию данных средствами GitHub.

## Результаты

| Показатель | Первичный рынок | Вторичный рынок |
|---|---:|---:|
| Средняя цена в 2019 году, тыс. руб./м² | 64,1 | 58,5 |
| Средняя цена в 2024 году, тыс. руб./м² | 177,9 | 114,1 |
| Изменение средней цены за период | +177,54% | +95,04% |
| Реальный прирост индекса за 2024 год | −0,66% | −2,67% |

Разрыв средних цен в 2024 году составил 55,92% к вторичному рынку. Первичный сегмент демонстрирует более сильный рост среднего уровня, однако приросты индексов обоих сегментов за 2024 год оказались ниже инфляции.

## Методика

- Изменение средней цены: `(Pтек / Pпред − 1) × 100%`.
- Прирост индекса: `опубликованный индекс − 100%`.
- Реальный прирост: `(индекс / (100 + инфляция) − 1) × 100%`.
- Разрыв сегментов: `(первичный / вторичный − 1) × 100%`.
- Связи с макрофакторами: корреляция Пирсона и проверка чувствительности исключением одного года.

Средняя цена и индекс — разные показатели. Корреляции по шести наблюдениям не доказывают причинность. Ключевая ставка на конец декабря не равна среднегодовой или ипотечной ставке. Сценарии кредитного платежа рассчитаны для 6 млн руб. на 240 месяцев; сценарные ставки не являются предложениями банков.

## Запуск

Из корня репозитория:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/analyze.py
```

После расчёта открыть `reports/market.xlsx` или локальный файл `site/index.html`. Графики поддерживают выбор диапазона, переключение рядов через легенду и масштабирование. Библиотека Plotly включена в проект.
