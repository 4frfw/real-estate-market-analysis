# Приёмка
Проверить Analytics and Pages: build и deploy. Если Pages запрещён: Settings → Pages → GitHub Actions. URL брать из фактического environment.
Запустить Weekly verified backup, проверить релиз и скачать независимую копию. Wiki, Issues, Discussions и Projects сохраняются отдельно.
Опубликовать Wiki и Discussion, получить настоящий ответ. Создать Board Todo / In progress / Done, добавить реальные Issues по acceptance.csv. Затем Capture actual progress сохранит снимки; для линии нужно минимум два реальных наблюдения. После снимка повторно запустить Analytics and Pages для публикации HTML. Историю задним числом не создавать.
Подготовленные файлы не равны опубликованным сервисам. Неподтверждённые пункты отмечены красным в отчёте.
